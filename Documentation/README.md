# Text Similarity Analyzer

The **Text Similarity Analyzer** is a console application written in **C#** that compares input texts (documents, words, or phrases) and calculates the semantic similarity between them. The project also includes a **Python Dash** application for visualizing the similarity results.

## Architecture
The solution consists of two main components:

### 1. **C# Text Analysis Application**
- **Purpose**: Computes similarity scores between input texts.
- **Input**: At least one query text (word, phrase, or document) and at least one reference text (word, phrase, or document).
- **Processing**:
  - Reads input files.
  - Calculates similarity scores using the OpenAI embedding model.
- **Output**: Saves similarity scores and embedding vectors in an output directory.

### 2. **Python Dash Visualization**
- **Purpose**: Provides a web-based interface to visualize and analyze similarity results.
- **Input**: Reads similarity and embedding data generated by the C# application.
- **Output**: Interactive graphs for similarity and scalar values of embeddings visualization.

### Modes of Operation
1. **Compare Words/Phrases with Words/Phrases:**
   - Both query and references are words or phrases.
   - Expected input: Two `.txt` files with query and reference words/phrases (each word/phrase on a new line).

2. **Compare Documents with Words/Phrases:**
   - Query documents are compared with reference words/phrases to find the most relevant documents.
   - Expected input: A folder containing `.txt` or `.pdf` query documents and a `.txt` file with reference words/phrases.

3. **Compare Documents with Documents:**
   - Query documents are compared with reference documents to assess contextual alignment.
   - Expected input: Two folders containing query and reference documents.

## Setup Instructions

### **Option 1: Running from .NET SDK**

#### Prerequisites
- **.NET SDK**
- **Python (3.x) with pip** (for the visualization app)

#### 1. Clone the Repository
```sh
git clone https://github.com/nishta168/TextSimilarityAnalyser.git
```

#### 2. Open the Solution File in Visual Studio

#### 3. Configuration

![Creating Configuration File](https://github.com/user-attachments/assets/db57a1e2-efe1-40f9-8919-202bc709e4d7)

*Fig 3. Creating configuration file.*

- Create an `appsettings.json` file in the root of the main project **MySemanticAnalysisSample**.
- Copy the contents from `appsettings.example.json` (also in the root of **MySemanticAnalysisSample**) to `appsettings.json`.
- Configure the API key and input text paths. As shown in fig 4, edit the first portion of input file paths to point to the location of the repo in your machine.

Note: Input paths can be locations outside the repo also, but using the "Input" folder inside the "MySemanticAnalysisSample" root is more intuitive for initial    setup.

![Configuring Input Paths](https://github.com/user-attachments/assets/0988b6b0-2d68-4997-bf91-a97b582d1e04)
*Fig 4. Configuring input paths and API key.*

#### 4. Running in Mode 2: Compare Documents with Words
- Enter the input query documents and reference words in the "Input" folder in the root of the project. *(Sample files are available in the **Input** folder, so this step can be skipped.)*

![Sample Input](https://github.com/user-attachments/assets/5ba2fb9a-3690-48ee-91ab-10d0868f3b27)

*Fig 5. Sample input present in the repository.*

- Either set the mode in `appsettings.json` and run the application or use command-line arguments to run the application:

![Setting Mode](https://github.com/user-attachments/assets/18510faf-58e4-4de3-8c3c-33e38ab655b8)

*Fig 6. Set mode in `appsettings.json` and run the app.*

- Or to run using command-line arguments:
```sh
dotnet restore
dotnet build
cd .\MySemanticAnalysisSample\  # Navigate to the project directory
dotnet run --mode CompareDocumentsWithWords
```
(For other modes enter their corresponding mode argument (--mode CompareWordsWithWords for mode 1 and --mode CompareDocumentsWithDocuments for mode 3) and give their expected inputs. This  part is discussed to the end in detail)

Once the program finishes execution, the similarity CSV and embedding vectors CSV are saved in the debug folder.

![Console Output](https://github.com/user-attachments/assets/945021ef-4121-45a3-8dcd-1892295dd36f)
*Fig 7. Console output.*

### 5. Visualizing the Results
A Python Dash application (`app.py`) is present in the Debug folder. It reads the output CSV and visualizes the results in an interactive dashboard.
Before running this application ensure Python (3.x) with pip is installed. To check if Python is installed on your laptop:  

#### **Windows**  
1. Open **Command Prompt** (`Win + R`, type `cmd`, press Enter).  
2. Type:  
   ```sh
   python --version
   ```  
   or  
   ```sh
   python3 --version
   ```  
3. If Python is installed, you'll see a version number (e.g., `Python 3.10.6`).  

If Python is not installed, download it from [python.org](https://www.python.org/downloads/).

#### Running the Visualization App
```sh
cd .\bin\Debug\net9.0\  # Navigate to the output folder
pip install dash plotly pandas numpy  # Install dependencies
python app.py  # Run the visualization app
```
